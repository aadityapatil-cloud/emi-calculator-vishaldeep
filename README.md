# Loan Repayment Dashboard

## 🌐 Live Demo

**View the live dashboard:**
[Loan Repayment Dashboard](https://emi-calculator-vishaldeep-1.onrender.com)

The dashboard is deployed on Render and can be accessed directly from a web browser.

## 📊 Project Overview

The **Loan Repayment Dashboard** is a web-based dashboard designed to calculate EMI and analyze loan repayment information.

Users can enter loan details such as loan amount, interest rate, and loan tenure to calculate EMI and view the repayment breakdown.

## ✨ Features

* 💰 EMI Calculator
* 📊 Loan repayment analysis
* 📈 Year-by-year repayment breakdown
* 💵 Total interest calculation
* 🏦 Multiple loan types
* 🎚️ Interactive sliders
* 📋 Year-by-year repayment table
* 📊 Principal and interest visualization
* 📱 Responsive web design

## 🏦 Supported Loan Types

## 🚀 How to Run Locally

### Method 1 – Open Directly

1. Clone or download the repository.
2. Open the project folder.
3. Open `index.html` in your browser.

### Method 2 – VS Code

1. Open the project in VS Code.
2. Install the **Live Server** extension.
3. Right-click `index.html`.
4. Select **Open with Live Server**.

## 🌐 Deployment

The project is deployed as a **Static Site on Render**.

### Render Settings

* **Service Type:** Static Site
* **Branch:** `main`
* **Root Directory:** Leave blank
* **Build Command:** Leave blank
* **Publish Directory:** `.`

No Python, FastAPI, Uvicorn, or `requirements.txt` is required.
